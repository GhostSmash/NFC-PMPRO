Быстрый старт

  1. Закройте NFC_Pro.exe и подключите кабель.
  2. Дождитесь зелёного статуса подключения.
  3. Положите карту на считыватель.
  4. Вкладка «Сканер» сама определит тип и заполнит данные.
  5. MIFARE: чтение и запись секторов, дампы, подбор ключа.
  6. 125 кГц: чтение EM4100 и запись T5577/EM4305.

Сканер меток

Готово к сканированию

Положите карту или брелок на считыватель и нажмите «Сканировать». Программа определит тип метки и откроет нужную вкладку с заполненными данными.

Опрос идёт по очереди: 13.56 МГц → 125 кГц → HID (до ~10 секунд, если метки нет).

125 кГц — это EM4100/EM4200, T5577, EM4305. Метка читается как 5 байт: customer + 4 байта номера.

Словарь ключей

Пробует ~30 частых ключей, начиная с FFFFFFFFFFFF. Найденный ключ попадает в Key A на вкладке MIFARE.

Проверка magic-карты

Определяет, можно ли менять UID: gen1a — по backdoor-команде, gen2/CUID — по пробной записи блока 0 с восстановлением данных.

Положите карту на считыватель и нажмите кнопку.

Настройки

Инструкция

Подключение

  • Полностью закройте NFC_Pro.exe — она захватывает устройство.
  • «Отключить» освобождает устройство; для работы подключите его снова.

Сканер

  • Опрашивает 13.56 МГц, затем 125 кГц, затем HID, сам открывает нужную вкладку и заполняет поля записи.

MIFARE

  • По умолчанию Key A = FFFFFFFFFFFF; кнопка рядом выбирает Key A, Key B или оба.
  • «Форматировать» сбрасывает сектор: данные в 00, ключи в FF.
  • Каждая запись проверяется обратным чтением.

Ограничения

  • Обновление прошивки не поддерживается — риск «кирпича».
  • Блок 0 с UID перезаписать нельзя.
  • Записывайте только свои метки или те, на которые есть разрешение.
